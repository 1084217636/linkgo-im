## 当前真实主链

客户端通过 `public/index.html` 登录并建立 WebSocket；Gateway 负责认证、连接维护和上行转发，Logic 负责消息 ID/会话序号、持久化和投递选择，Redis 保存在线路由及短期 ACK/补偿状态，群聊任务进入 Kafka 后由 Transfer 按收件人投递。

## 不能夸大的边界

- 【当前已实现】消息历史主要落 MySQL；Redis Pub/Sub 只承担在线通知，不能作为可靠历史存储。
- 【当前已实现】重连补偿依赖 Redis 的 pending/ACK/timeline 短期数据，MySQL 历史查询是独立接口。
- 【当前已实现】红包是等额账本模型，不等于完整钱包、退款和对账系统。
- 【当前已实现】AI 虚拟好友默认存在 mock/轻量召回边界，不能描述成生产级 Agent 平台。
- 【未来方案，当前未实现】多机房容灾、完整读写分离、自动扩缩容和真实生产集群证据。
